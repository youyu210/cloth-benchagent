# 逐项校验清单说明

检查清单随单项 report.json 保存，版本为 benchagent-checks-v1。
原有指标键、整体状态码及物理求解实现保持稳定，新增 checks_schema 与 checks 字段。
Markdown 报告和界面均提供中文检查表。

## 每个检查的内容

| 字段 | 含义 |
|---|---|
| id | 稳定检查编号 |
| name | 中文检查名称 |
| required | 是否为必需检查 |
| status | PASS / FAIL / WARNING / SKIPPED |
| expected | 期望值或固定约束 |
| actual | 当前实际观测，未取得时为 null |
| evidence | 相对单项运行目录的证据路径 |
| message | 中文检查说明 |
| details | 检查失败或告警时的具体原因，展示时翻译为中文 |

证据路径表示该检查的来源或所需材料，不保证失败或跳过时文件已产生；
SKIPPED 且 actual=null 表示未取得判断依据，不表示文件缺失已通过检查。
异常观测中的 NaN / Inf 转为明确的非有限数值文本，保留失败结论并允许 JSON 归档。

## 检查编号

| 编号 | 检查项 | 必需 |
|---|---|---|
| P00 | 环境与固定文件前置检查 | 是 |
| V01 | 进程正常结束 | 是 |
| V02 | 唯一完成标记 | 是 |
| V03 | 实际帧数与连续帧序号 | 是 |
| V04 | 程序完成状态 | 是 |
| V05 | 文件新鲜度与运行身份 | 是 |
| V06 | 必需指标可读且数值合法 | 是 |
| V07 | PCG 聚合与明细一致 | 是 |
| V08 | PCG 求解明细覆盖率 | 否 |
| V09 | 默认场景与初始状态 | 是 |
| V10 | 固定 C0 配置 | 是 |
| V11 | 状态有限且保护预算未触顶 | 是 |
| V12 | Graph 实际执行且无回退 | 是 |
| E00 | 工具链执行接口异常（仅异常时增加） | 是 |

## 状态关系

- 必需检查失败时，整体任务为 FAIL。
- V08 是非关键覆盖率检查；PCG 明细部分缺失时为 WARNING，保留覆盖率，整体可为 PASS。
- 前置检查不通过时 P00 为 FAIL，整体任务为 SKIPPED；运行阶段各检查均为 SKIPPED。
- 进程超时或异常退出时 V01 为 FAIL；尚未解析的统计检查为 SKIPPED。
- 文件损坏时 V06 为 FAIL；依赖该文件的完成状态、帧数、C0 等检查不补判通过。
- 当前 V06 使用 parse_artifacts 的格式与数值验证结果。只有解析完成才记录为通过。
- 此清单验证任务执行和统计证据，不新增物理精度或无穿透认证。
- 历史报告没有 checks 时，展示“未记录”，不制造历史通过记录。
