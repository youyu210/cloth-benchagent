# BG06 统一报告导出交付

BG-06已接入中文Markdown、JSON、CSV、PDF和ZIP证据包。220项Python回归通过，其中新增28项导出与界面测试。
最终中文PDF共9页，已实际渲染并逐页检查；下载文件的渲染与已检查页面完全一致。
本轮只读取已有归档，未启动新GPU仿真、真实模型调用或原生构建。

## 使用

重启原工作台进程加载新版，启动入口不变：

~~~powershell
& 'D:\benchagent\scripts\start_workbench.cmd'
~~~

进入测试报告，选择归档与分析用例，再选择导出范围、格式，点击生成导出文件。
生成后提供文件和产物清单下载。打开页面、切换格式或用例不会自动生成导出或启动任务。

| 范围 | 内容 |
|---|---|
| 当前报告 | 单项报告的统一视图和允许来源 |
| 当前用例 | 所选用例的指标及详细证据；保留任务集总摘要用于溯源 |
| 整个任务集 | 所有可读取子报告及对应证据，不简单平均各用例指标 |

当前新工作器任务仍在运行时不生成最终导出。历史部分、失败或损坏记录保留其原结论和读取状态，不重判。

## 格式与口径

| 格式 | 内容 |
|---|---|
| Markdown | 中文结论、各用例指标、关键帧、检查、运行配置与异常 |
| JSON | 统一archive-view-v1、来源清单；原报告文件以Base64和SHA256保留精确字节 |
| CSV | 中文列头、全部实际逐帧值、原校验结论、读取状态及缺项说明 |
| PDF | 嵌入中文TrueType字体、矢量曲线、指标、关键帧、逐项检查和日志摘要 |
| ZIP | 统一Markdown/JSON/CSV、白名单原始证据及内部成员哈希清单；PDF单独下载 |

PCG主卡及逐帧字段按次/帧；每次求解平均在指标明细另列。
CSV保留解析后数值精度，缺失数值留空，碰撞缺项在原因列标记未记录，不补零。
清单记录中文列到机器字段、单位的映射，以及格式、视图版本、语言和舍入策略。
CSV中以公式符号开头的文本标识加前导单引号；原报告字节仍由JSON/ZIP保留。

## 目录与模块

导出独立保存在D:\benchagent\exports，不写runs原件。文件名采用内容关联标识；
每个产物配套manifest.json，记录来源摘要、来源文件哈希、当前版本与输出文件SHA256。
旧格式版本的缓存可留存，但接口不会把它当作当前版本返回。

| 文件 | 职责 |
|---|---|
| benchagent/export_service.py | 来源快照、范围约束、缓存、白名单、原子发布与下载校验 |
| benchagent/export_document.py | 共用快照到Markdown/JSON/CSV的转换和溯源元数据 |
| benchagent/pdf_report.py | 嵌入中文字体、表格分页、矢量曲线及PDF版本指纹 |
| benchagent/ui_exports.py | 明确生成、范围/格式选择、文件与清单下载 |
| benchagent/app_service.py | 导出能力、生成和内容读取的应用入口 |
| configs/pdf_export_acceptance.json | 当前PDF渲染器/共享视图/字体/库版本的验收记录 |
| dependencies/fonts、pdf_dependencies.json | 本机字体的项目副本及离线依赖来源 |
| scripts/verify_bg06_exports.py | 已有原生归档的五格式离线交叉核验 |
| tests/test_exports.py、test_export_ui.py | 新增21项服务测试及7项界面测试 |

PDF依赖reportlab 4.4.9、pypdf 6.10.0，已从捆绑运行环境离线复制进项目.venv，依赖检查通过。
字体来自本机Windows，项目内副本参与渲染指纹；交付PDF嵌入所需字体子集。

## 来源与缓存

缓存标识同时绑定来源摘要、范围、格式、语言和当前导出实现。
相同输入可复用，源报告、CSV或相关版本变化后旧下载会失效，要求重新生成。
读取下载时再次核对当前来源与产物SHA256，损坏文件不直接返回；重新生成可修复缓存。
生成期间来源变化不发布成功清单。

来源仅限允许归档目录及预定义文件名，拒绝链接、联接和路径越界。
ZIP保留原目录层级，不平铺同名文件，不跟随.env、密钥文件或任意额外目录。
单文件上限64MiB、总来源和产物上限128MiB、文件数上限500，超限报错，不静默截断。

## PDF验收

当前9页覆盖套件概览、两用例完整指标、曲线、关键帧、逐项检查、配置、日志及溯源。
中文显示、边界、页码、表头和分页已经实际检查；最终文件逐页PNG哈希与检查版本一致。
渲染器、共用视图、字体或ReportLab版本变化后，PDF下载自动回到待验收状态。

极长检查字段显示上限6000字符，明确标注截断；日志显示末尾6000字符。
不支持的字形以Unicode编号显示并在清单记录。完整原文与原始日志由JSON/ZIP保留。
浏览器页面的桌面/窄屏/滚动验收仍待补充；PDF渲染验收不等于浏览器视觉验收。
