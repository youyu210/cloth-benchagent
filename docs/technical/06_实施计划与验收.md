## 2. 首条具体开发任务：BG-01

已新增 archive_repository.py 与 view_models.py，复用已有 presentation 字典和报告渲染基础。
86 项离线测试通过；4 个归档入口、8 个单项回放通过，224 个归档文件哈希未变。
见 [实现说明](BG01_实现说明.md)。正式页面接入属于 BG-04/05。

交付：

1. 识别旧单项目录、旧套件子目录和目标新目录结构。
2. 只读加载 report/summary，保留原始 verdict 与原字段。
3. 为空、完整、部分、缺字段、损坏记录生成带来源的统一视图。
4. 提供当前六卡的指标字典，PCG 主卡按帧，求解口径另列。
5. 实际不存在的逐帧碰撞列明确未记录。
6. 给出合成/旧记录测试，不修改 runs/ 中任何文件。

历史归档损坏时，archive_read_status 与 recorded_result_status 分开。
不能为了统一界面把旧 PASS 重写为新 FAIL，也不能因为旧摘要 PASS 就忽略文件缺失。

不属于 BG-01：异步运行、改求解器、真实模型、界面完整替换、真实仿真采样。

## 3. 离线验收矩阵

| 验收编号 | 场景 | 预期证据 |
|---|---|---|
| AC-01 | 发送消息、预览、页面重绘 | 仿真启动次数为 0，不创建真实运行目录 |
| AC-02 | 修改草稿后提交旧摘要 | PLAN_STALE/版本冲突，旧成绩不挂到新计划 |
| AC-03 | 同请求重试、双击提交 | 同一 job_id，只有一次进程创建 |
| AC-04 | 单项、标准套件、自定义子集 | 白名单校验、固定顺序、同一租约、独立初态 |
| AC-05 | 时间步/容差/场景/命令覆盖 | 请求被拒绝，不修改配置、不启动 |
| AC-06 | 取消排队、准备、运行、报告阶段 | 明确终态，未启动用例跳过，既有结果保留 |
| AC-07 | 终止失败、PID 归属未知 | CLEANUP_REQUIRED，锁不释放，后续不启动 |
| AC-08 | 超时、非零退出、损坏 JSON、19 帧 | FAIL/对应检查与部分证据；不误判 PASS |
| AC-09 | CSV 半行、重复/乱序、旧路径 | 只确认合法连续新帧，异常可见，原文件不变 |
| AC-10 | 100% 帧数但仍在校验 | 不提前显示通过或完成报告 |
| AC-11 | 套件选中用例切换 | 卡片、曲线、表格、日志和报告引用一致 |
| AC-12 | PCG 缺项或零求解调用 | 覆盖率与缺项明确；分母为零显示未采集 |
| AC-13 | 旧报告缺 checks/逐帧碰撞 | 不补造通过项或碰撞值 |
| AC-14 | 切换合成、未执行、历史、实时 | 来源标识明确，旧状态不残留 |
| AC-15 | 导出、重新导出、源版本变化 | 同数据口径、正确缓存键、真实文件格式 |
| AC-16 | 默认禁用模型、过期回复（模拟） | 无网络，不改指标/状态，不启动任务 |
| AC-17 | 服务重启与未完成登记 | 恢复视图、记录 interrupted，不自动续跑 |
| AC-18 | 六导航、报告标签、键盘/窄屏 | 页面操作与状态一致，中文单位可读 |

运行器使用注入式模拟进程，模型使用 Disabled 或假适配器。
测试工作区位于 tests/ 下的隔离目录，不与真实 runs/ 混合。
真实二进制和外部在线服务不应被离线端到端测试误调用。

## 5. 视觉和 PDF 验收

实际浏览器视觉验收独立于模拟 DOM 检查：

- 桌面 1536×1024、1440/1280 宽及窄屏。
- 左侧聊天滚动、计划修改、右侧图表与关键帧、空状态和报告标签。
- 中文字体、单位、长哈希、证据路径和宽表无不可读裁切。
- 合成水印和模型待接入提示不会被滚动或截图省略得像真实运行结果。
- PDF 必须实际渲染检查，内容、中文、分页与来源报告对应。

已有自动预览工具拒绝本地 file 协议，当前未做真实浏览器视觉验收。
不能将静态源检查或模拟 DOM 的通过写成视觉已通过。
