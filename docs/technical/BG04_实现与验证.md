# BG04 六导航工作台交付

BG-04已按V3.1原型接入正式Streamlit界面：左侧对话与计划，右侧任务阶段与分析，六项导航共用应用服务。
分析表格、指标单位、任务状态及缺项说明保持中文。全部文件位于D:\benchagent。
156项Python回归通过，新增19项界面及服务接线测试。本轮未启动新的GPU仿真、模型调用或原生构建。

## 启动

~~~powershell
& 'D:\benchagent\scripts\start_workbench.cmd'
~~~

默认本机地址http://127.0.0.1:8514。cmd入口不受PowerShell的ps1执行策略限制，无需修改系统策略。
启动脚本使用项目.venv并关闭文件热重载；原ps1入口保留Port参数。
入口为ui.py；旧单页保存在docs/archives/ui_BG03.py。本轮验证用预览服务已停止。

## 模块与边界

| 文件 | 职责 |
|---|---|
| ui.py | 正式工作台入口 |
| benchagent/ui_app.py | 六路由、Streamlit控件与展示 |
| benchagent/app_service.py | 预览、确认提交、任务查询/取消、归档、受限日志与环境检查 |
| benchagent/ui_models.py | 界面上下文、中文状态、流程、套件行及合成演示 |
| benchagent/ui_assets/workbench.css | 原型色彩、卡片、侧栏与响应式样式 |
| .streamlit/config.toml | 本地主题 |
| scripts/start_workbench.cmd | 推荐本地启动入口，无需修改PowerShell执行策略 |
| scripts/start_workbench.ps1 | 原PowerShell入口，可配置Port |
| tests/test_workbench_ui.py | 新增19项界面与应用服务验证 |

AppService构造、读取页面和计划预览不创建工作器；明确submit才延迟启动JobManager。
Streamlit cache_resource在同一服务进程内复用AppService，页面重绘不重建工作器。
前端不调用runner.execute或Popen；规则回复标记本地规则，模型默认禁用。

新预览绑定唯一确认与执行请求标识，重试复用原值。
修改输入立即清除旧计划及提交标识，并切换到计划预览，不延续旧任务成绩。
已提交任务继续由后台管理，可从运行记录重新选中；页面切换不取消任务。
合成演示须显式打开，显示醒目标识并禁用真实提交。

当前任务绑定job_id查询阶段快照，阶段结束与最终校验分开。
取消回执显示已请求或正在收尾，不提前显示已取消。
真实结果仅在报告可读后展示；卡片、曲线、关键帧及日志绑定同一case_id。
日志当前为最多16000字节的只读尾部快照，尚无增量游标。

## 中文指标

六卡复用BG-01统一视图；PCG主卡按次/帧，次/求解在详细指标另列。
套件并列展示，不简单平均各项均值，不因查看或下载而改写原判定。
缺失数值显示未采集，逐帧碰撞显示未记录，不补零、不从累计值反推。
未执行、计划、当前任务、历史与合成分别标源，不从曲线推断性能优劣或物理正确性。
