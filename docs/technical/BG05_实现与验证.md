# BG05 连续帧进度与增量日志交付

BG-05已接入连续帧采集、按用例绑定的观测指标/曲线、增量日志与暂停跟随。
192项Python回归通过，新增36项。固定C0的20/50帧实测完成，70帧均通过原生证据检查。
所有新增文件位于D:\benchagent，原配置、求解器、运行器和验证器未改变。

## 启动与更新

已有工作台进程需要重启后加载新代码，启动入口不变：

~~~powershell
& 'D:\benchagent\scripts\start_workbench.cmd'
~~~

默认地址http://127.0.0.1:8514。本轮未启动新的浏览器预览，也未重试此前被策略中止的浏览器自动化。

## 页面行为

| 功能 | 当前行为 |
|---|---|
| 总进度 | 所选任务各用例已完整采集帧数之和 / 所选目标总帧数 |
| 用例进度 | 中文表显示已采集、目标、阶段和独立校验结论 |
| 当前用例跟随 | 默认跟随活动用例；关闭后可查看同任务其他用例 |
| 实时指标 | 仅用选中用例已采集帧统计，PCG均值按次/帧；标为实时观测 |
| 最终结果 | 任务归档后读取原报告，保持同一选中case_id，不用其他用例代替缺失报告 |
| 流程条 | 取该用例实际阶段事件；取消未经过的数据分析阶段不补完成 |
| 日志流 | 标准输出/标准错误独立游标，按任务与用例隔离 |
| 暂停跟随 | 只暂停日志读取，帧采集与仿真继续；恢复后从原字节位置续读 |

达到100%采集不代表校验通过。取消/失败不补足目标帧数，未启动项保持零采集并显示跳过。
实时视图没有PASS/FAIL，也不调用终态解析器；最终判定仍由原验证器产生。
ETA至少有5帧且用例运行中才显示，用最近最多20帧耗时估算当前用例剩余物理步；
不含初始化、校验及后续用例，不参与判定。

## 模块与接口

| 文件 | 职责 |
|---|---|
| benchagent/progress_reader.py | 只读CSV和UTF-8字节游标、来源校验及异常保留 |
| benchagent/app_service.py | telemetry(job_id, cursors)、log_slice(job_id, case_id, stream, cursor, follow) |
| benchagent/ui_telemetry.py | 2秒界面刷新、用例选择、实时观测与日志跟随 |
| benchagent/ui_models.py | 实时观测视图、按实际事件绘制流程 |
| benchagent/ui_app.py | 挂接实时组件，最终报告接受明确用例选择 |
| tests/test_progress_reader.py | 24项增量读取测试 |
| tests/test_app_telemetry.py | 12项服务/UI身份与联动测试 |

telemetry返回job-telemetry-v1，包括同次读取的任务快照、观测seq、各用例统计及下一次游标。
游标保存在调用方会话中，不回写runs或任务状态，刷新/重连可以从原文件重建。
新计划切走旧任务展示；已有缓存按job_id/case_id分区，不混用。

## CSV读取协议

只消费完整换行的单行CSV。半个表头、半行或未完成UTF-8内容留待下一次读取。
表头须含frame、step_ms、newton_iterations、pcg_iterations，允许原生额外诊断列。
帧号须从1连续递增且不超过目标；重复、乱序、缺口、无效值和超目标记录阻止后续自动续读，
保留此前确认的连续帧并显示异常，不跳过坏行拼接后续数据。

读取器检查非负有限耗时和非负整数计数。正式逐帧碰撞缺失仍为未记录；
累计碰撞不能由逐帧观测反推。记录结束仍有半行时明确提示而不计数。

游标绑定任务、用例和目标；文件身份、已消费前缀SHA256及字节位置共同验证。
源文件消失、截短、替换或改写均保留上次观测并报告，不静默从头复用。
每次读最多65536字节，源大小上限16MiB；前缀核验会额外读取已消费部分。
读取期间数据变化导致提交失败时撤回本轮新增内容，不把未确认行显示为进度。

## 日志字节协议

stdout/stderr分别绑定job_id/case_id/stream。
不完整UTF-8字节保留在未消费位置，不因缺换行丢正文；日志无需等待换行才显示。
遇到无效字节或终态不完整编码时显示替代字符并提示，源字节不改写。
界面缓存最近32000字符，明确提示截断；完整源文件保留，游标仍记录实际消费位置。
暂停保持游标与文本不变，恢复按原位读取积压；不控制执行器或GPU。

## 验证结果

192项回归全部通过，新增36项覆盖半行续读、表头、重复/乱序/超目标、
非法数值、来源替换/截短/改写、UTF-8拆字、暂停恢复、积压分块、读取竞态回退、
取消后实际进度、用例/输出流隔离、阶段条和界面身份切换。

14份历史原生帧流只读回放通过，398个原归档文件哈希未变。
[历史回放证据](BG05_历史回放.json)。

真实固定C0子集20/50帧分别从初态启动，得到71个进度/状态快照。
每项P00及V01–V12通过，计数单调，选中用例的观测分母与已采集帧一致；
日志在第3帧暂停后恢复，终态显示后缀与源日志一致。
采集到70/70时仍为ACTIVE，随后进入COMPLETED并发布PASS。
本轮0.05秒高频读取仅用于功能验证，不能作为正式性能样本。
