## 模块与接口

| 文件 | 职责 |
|---|---|
| benchagent/archive_repository.py | 只读索引、单项及套件适配、路径边界、JSON 和逐帧 CSV 读取 |

仓库的 get_report 返回含 raw_report 的归档适配记录，get_view 才返回展示视图。
技术规范 02 中的 get_report 是未来 AppService 的展示接口，届时委托 get_view。
当前仓库支持原记录状态过滤及 offset/limit 分页；时间筛选和游标仍属后续服务层工作。

## 归档兼容与状态

支持旧单项 report.json、旧套件 benchmark_summary.json 加直属子任务，以及新 cases/ 子任务结构。
新 cases/ 缺少摘要时仍能读取子报告，但套件结论未知；缺失子报告时只展示摘要中实际记录的数据，并标注真实来源。

recorded_result_status 保留原报告结论，archive_read_status 单独表示完整可读、部分可读、读取失败或归档未完成。
损坏 JSON、缺证据、套件与子项冲突均产生 issues；不修改原 PASS/FAIL，也不调用验证器重新判定。
缺字段使 data_source.completeness 为 partial；文件可读取不等于数据完整。

所有路径须位于归档根及对应报告目录内，拒绝绝对路径、上级跳转、越界链接和循环套件引用。
返回值复制原始对象，调用方修改视图不会写回归档。

## 指标口径

| 展示项 | 计算或读取口径 |
|---|---|
| 平均帧耗时 | 物理步总秒数 × 1000 / 实际帧数，毫秒/帧 |
| 平均牛顿迭代 | 牛顿总次数 / 实际帧数，次/帧 |
| 平均 PCG 迭代主卡 | CSV 聚合总次数 / 实际帧数，次/帧 |
| 平均 PCG 迭代详细项 | 同一聚合总次数 / 求解调用数，次/求解 |
| 总牛顿、总 PCG | 已记录聚合总量 |
| 累计碰撞计数 | 原记录 collision_counter_total，不解释为检测调用数 |

分母缺失或为零、非法数值、布尔数值均显示未采集。
总量与记录均值不一致时，统一视图按总量和分母计算，原值留在 raw_report/recorded_value 并显示说明。
逐帧数据优先读取合法连续 frames.csv；不可用时可回退到报告中的合法耗时数组。
无逐帧牛顿/PCG 数据显示未采集，无逐帧碰撞列显示未记录。
旧记录缺 checks 不补造通过项；明确 synthetic 的样例保留合成标识，其他旧记录不推断为真实来源。
