# V3 页面与交互规范

原型参考：reference-v3.png。可点击设计稿：benchagent-v3-prototype.html。
设计稿只切换页面布局，不读历史文件，不调用当前运行器，不调用模型，不生成实验结果。

## 导航地图

| 一级导航 | 内部页面 | 主要操作 |
|---|---|---|
| 首页 | 项目入口 | 创建任务、查看测试记录 |
| 基准测试 | 配置 / 执行监控 / 结果概览 | 预览计划、正式运行、取消、选中用例、看完整报告 |
| 测试记录 | 归档列表 / 任务详情 | 筛选与回放已有记录 |
| 报告管理 | 报告列表 / 报告详情 | 查看、下载、定位证据 |
| 系统设置 | 环境 / 执行保护 / 模型预留 | 本地检查、读取配置、查看模型禁用状态 |

任务切换时保持选中用例；返回记录列表不自动创建或恢复物理进程。
设计稿中的“查看执行页”等按钮只展示下一页，不对应真实提交。

## 版式

- 侧栏采用深蓝紫，产品名称分两行，活动项采用紫色强调。
- 正文采用浅色底、白色卡片、轻边框；重要数据用深色，次要说明用灰紫。
- 顶栏放当前路径、固定场景标签及模型待接入标签。
- 主页采用双栏：左侧介绍与入口，右侧场景示意；不虚构场景渲染画面。
- 结果页采用四卡加“所选用例曲线 / 用例汇总表”双栏；窄屏改纵排。
- 报告页采用四标签，技术细节下沉；所有数据表均有中文名与单位。
- 普通按钮和表单有清晰焦点；活动状态使用文字和样式共同表达。

## 配置交互

标准评测选择 20、50、100 三项，并锁定其勾选。
自定义允许从三项中任选非空子集；选空时不能提交。
高级参数不接受修改，区分文件快照与运行后实际参数。
模型入口不与必填配置混在一起，默认“待接入”。

## 监控交互

显示当前阶段、当前用例、已确认帧数、整套已确认进度和日志。
不提供伪实时视频，不播放与当前任务无关的场景动画。
任务取消需要服务确认进程结束；界面在确认前保持“取消中”。
本地页面刷新只查询已有 job_id，不重复 submit。

## 结果交互

三个性能指标都来自当前选中的一个用例。
第四卡显示本次任务集合的校验通过数量，明确分母包含失败与跳过项。
PCG 主卡按每次求解平均，若显示每帧口径须另起指标并写清单位。
切换用例时，卡片、图表和明细同步切换。
没有有效数据时展示缺失原因，不用 0 代替。

## 模型接口区域

设置页仅展示：
- 模型接口：待接入。
- 默认实现：DisabledGateway。
- 预留能力：候选计划、报告解释。
- 正式配置与连接检查：后续开发，当前按钮禁用。

现有 planner.py 的实验性实现不接入新页面。
后续模型解释放在确定性结论之后；不得把解释文本呈现为新的 PASS/FAIL。

## 原型与实施区分

此次可点击稿可用于确认导航、页面层级、只读边界和信息密度。
它不是已上线或已连接后端的 BenchAgent；当前 ui.py 仍保留原实现。
后续按 V3 任务书分阶段替换页面，复用既有报告和检查数据。
