# V3.1 智能测试工作台原型

日期：2026-11-02。依据本次新增参考图 reference-v3-1.png 修改。
当前设计稿：benchagent-v3-1-prototype.html；样式与交互为同目录的 .css / .js。
旧 benchagent-v3-prototype.html 保留，作为上一版设计记录。

本轮修改的是独立可点击原型。没有替换 ui.py，没有启动真实任务，也没有连接模型。
合成演示只是界面示例，不是实验或真实历史报告。

## 1. 从多页入口改为同屏工作台

| 区域 | 新设计 |
|---|---|
| 侧栏 | 智能测试、基准任务、运行记录、测试报告、配置管理、系统设置 |
| 顶栏 | 智能基准测试、D:\benchagent、待载入的实际环境信息 |
| 左侧 | 对话需求、规则计划、修改计划、合成结果摘要、输入框 |
| 右上 | 六步流程：任务解析、环境检查、配置参数、运行仿真、数据分析、生成报告 |
| 右侧主体 | 运行概览、六项指标、耗时/迭代曲线、分析说明、关键帧、日志摘要 |
| 底部 | 查看报告布局；真实 PDF / CSV 导出接入前禁用 |
| 模型区 | 明确显示“模型待接入”，不展示已连接、厂商或模型型号的假状态 |

原参考图中的 D:\Stiff-GIPC、RTX 4090 / CUDA 12.4、模型已连接和性能数字均不继承为真实信息。
默认场景仍是源码 scene_no=1 软体—刚体—布料耦合；场景图为标注过的概念示意。

## 2. 可点击交互

1. 六项侧栏可以切换页面，智能测试为默认入口。
2. “修改计划”可选择 20 / 50 / 100 帧；应用后只更新计划，并清空展示成绩。
3. 输入“默认场景运行50帧，分析耗时与迭代”等请求，可生成本地规则计划预览。
4. 非法帧数、其他场景或容差/摩擦等修改请求被拒绝；不会提交工具命令。
5. “合成演示”显示可重复生成的示例曲线、指标、关键帧及样例日志。
6. “未执行”清除示例数字、曲线和完成样式；缺失值不补零。
7. “查看报告布局”打开报告页，支持概览、配置、详细检查、日志标签切换。
8. 开始执行、模型连接、PDF/CSV 下载等真实操作保持禁用。

正式产品的标准套件功能继续保留；本次原型的对话联动只展示一个所选固定用例，
不是对白名单任务集能力的删除，也不声称已实现异步任务后端。

## 3. 原型数据与指标口径

演示数据使用确定性的纯 JavaScript 合成序列，不读取 runs/ 或调用当前仿真程序。
每次切换帧数都由同一序列重新计算，表格、图表、摘要和报告预览使用同一份数据。

| 指标 | 计算与说明 |
|---|---|
| 物理步总耗时 | 示例逐帧耗时之和 / 1000，单位秒 |
| 平均帧耗时 | 示例逐帧耗时之和 / 帧数，单位毫秒/帧 |
| 平均牛顿迭代 | 示例牛顿总次数 / 帧数，单位次/帧 |
| 平均 PCG 迭代 | 示例 PCG 聚合总次数 / 帧数，单位次/帧 |
| 牛顿 / PCG 总次数 | 对应示例逐帧计数求和 |
| 累计碰撞对计数 | 单独的合成汇总值，仅用于演示汇总卡，不宣称为碰撞检测调用次数 |
| 逐帧碰撞对计数 | 现有正式数据缺少该项时显示“未记录”，不从累计值反推 |

V3.1 为使均值和总计直观对应，主卡 PCG 明确改为“次/帧”。
后续完整报告如需“每次 PCG 求解平均”，应另列为 PCG 总次数 / 求解调用次数，
不能复用同一个字段或标签。

分析说明不会因为合成曲线看起来平稳就给出“性能良好、符合预期”或物理正确的结论。
在未执行模式下不预设任何 PASS / FAIL。

## 4. 对后续正式界面的约束

- 对话草稿、已确认计划、正在执行任务和报告结果必须分开保存并通过标识关联。
- 修改计划使旧的确认失效；历史结果仍属于旧任务，不作为新计划的成绩。
- 真正开始执行只由用户明确动作触发；自然语言解析、模型回复与页面重绘不得自动启动进程。
- 模型未接入时继续提供清楚标识的规则预览或表单入口；不伪装为 LLM 返回。
- 六步流程只能由实际任务服务事件推进；当前紫色示意不是实际任务完成记录。
- 配置管理继续保持固定 C0 和只读求解参数；模型适配与实验功能仍后置。

## 5. 验证范围

14 项静态/模拟 DOM 逻辑检查通过，覆盖页面路由、计划预览、数据联动、分母、
空状态、请求拒绝、标签页和禁用边界。
这不是实际浏览器渲染或响应式视觉验收；本轮未进行浏览器视觉验收。
原有 60 项 Python 测试是上一阶段记录，本轮未改动或重新运行后端测试。
