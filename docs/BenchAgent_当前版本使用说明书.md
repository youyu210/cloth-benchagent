# 布料仿真 BenchAgent 功能说明

文档日期 2026-11-18。适用于 Windows 下 D:\benchagent 的 V4 工作台，包含材料参数配置与历史实验分析。环境准备、命令行启动、独立构建和验收复现见 [配置、构建与运行说明](BenchAgent_配置与启动说明.md)。

## 工作台入口

| 页面 | 主要操作 |
| --- | --- |
| 智能测试 | 从手动表单或 DeepSeek V4 生成计划。预览并确认后运行 GPU 仿真。可在本页打开历史实验分析。 |
| 运行记录 | 找回任务和历史归档。打开任务后查看进度、日志和结束状态。 |
| 测试报告 | 按用例查看指标、逐项检查、原生画面、运行配置和异常日志，按需导出。 |
| 配置管理 | 查看固定求解配置、原生参数数组和版本信息。通过智能测试为单次任务配置布片材料。 |
| 系统设置 | 检查运行环境、查看工作器占用、配置 DeepSeek 会话密钥。 |

## 创建并运行任务

1. 「智能测试」采用左侧助手、右侧任务工作区。左侧提供「手动表单」「DeepSeek V4」两个入口，默认 DeepSeek V4。DeepSeek 模式需要先在「系统设置 → 模型接口」保存有效密钥。
2. 右侧包括「任务计划」「运行监控」「结果报告」「历史实验分析」四个页签。表单在「任务计划」中填写，对话生成的计划会同步到本页签。
3. 表单中选择测试场景和帧数。固定帧数提供 20、50、100 三个快捷选项，自定义帧数支持 1–1000 的整数。需要画面时勾选「采集原生画面（初态、中间帧、末帧）」。
4. 点击「预览计划」或「发送并预览」。核对场景、帧数、可执行文件和材料参数，再点击「确认并开始执行」。对话计划可展开「调整任务计划」，直接修改场景、帧数和材料参数，并点击「应用修改并重新预览」。有未应用修改时，执行按钮禁用。
5. 在「运行监控」查看完成帧数和日志。结束后从「运行记录」找回任务，或到「测试报告」选择对应归档和用例。

已登记的十二个场景包括软体／刚体／布料耦合、箱管、摆锤、固定布料、扭转垫、大规模箱管与布料、箱体排列、悬挂布料、球体与布料、兔形障碍与布料、桌面与布料、十层布料堆叠。表单按场景类别筛选。对话可使用明确场景名，例如「运行悬挂布料，20帧，并采集原生画面」。新计划省略帧数时使用目录默认的 20 帧。 [场景能力目录](../configs/scene_catalog.json)

## 按任务配置布片材料

| 场景与对象 | 默认膜杨氏模量（Pa） | 默认体密度（kg/m³） | 默认泊松比 |
| --- | ---: | ---: | ---: |
| 固定布料的单布片 | 50 000 | 200 | 0.49 |
| 悬挂布料的单布片 | 821 000 | 472.641509 | 0.243 |
| 球体与布料场景的布片 | 1 000 000 | 200 | 0.49（只读） |

膜杨氏模量的输入范围为 1 000–10 000 000 Pa。体密度的输入范围为 10–2 000 kg/m³。可编辑场景的泊松比范围为 0–0.49。杨氏模量影响面内拉伸和剪切，密度改变顶点质量与惯性，泊松比参与面内和弯曲系数计算。厚度、弯曲模量、摩擦、网格及固定点按场景预设。球体的材料参数和多片布料的逐对象参数当前未开放。 [材料参数能力清单](BenchAgent_材料参数能力清单.md)

| 操作 | 示例 |
| --- | --- |
| 查看真实默认配置 | 在 DeepSeek 入口输入「查询固定布料的材料参数」。如果会话已有同场景计划，可查看当前计划值。 |
| 按倍数修改 | 「把固定布料的杨氏模量改成原来的两倍，运行20帧。」从场景默认值或同场景上一份有效计划计算。 |
| 同时指定多个值 | 「将固定布料的杨氏模量改成100 kPa，并把体密度设为300 kg/m³。」界面会换算并显示标准单位。 |
| 继续修改 | 「把泊松比改成0.3，其他参数保持不变。」同场景承接上一份有效材料计划。也可输入「把杨氏模量降低20%」。 |
| 恢复默认 | 「恢复这个场景的默认材料参数。」表单中可勾选「恢复场景默认值」。两种方式都生成一份待确认的新计划。 |
| 提出定性需求 | 「让布料更柔软一些，并给我一个合理的参数修改方案。」界面给出可对照的参数方向，明确数值后再提交预览。 |

表单入口为「智能测试 → 表单配置 → 布片材料参数 → 为本次任务配置材料」。预览展示默认值、修改前的计划值、本次计划值、单位和预期影响。膜杨氏模量可用 Pa、kPa 或 MPa，密度可用 kg/m³，裸数按表中的标准单位解释。确认后每个用例加载自己的材料 JSON。完成后在「测试报告 → 运行配置」查看实际生效值，并在「详细指标与检查」核对 M01。M01 将计划与原生初始化记录、派生 FEM 系数和 GPU 回读质量进行核对。 [材料参数验收](BenchAgent_材料参数验收.md)

## 历史实验分析

在「智能测试 → 历史实验分析」页签中打开历史实验分析。可按目标场景查询归档，也可明确选择一个已完成的用例。点击「填入球体与布料示例」后再点击「查询归档并分析」。启用 DeepSeek 工具选择时，模型根据场景标识、证据需求和前序工具观测，从允许的工具中建议下一步。

| 归档证据情况 | 工作台行为 |
| --- | --- |
| 证据充分 | 直接分析现有归档，显示高耗时帧、Newton／PCG 迭代、适用的接触相关计数，以及对应的原生画面。 |
| 缺项可以补测 | 在预算内提出诊断方案，展示新增采集项。点击「确认配置与预算并提交补测」后启动，之后可点击「刷新补测并读取结果」。 |
| 当前无法补齐 | 显示已有分析和缺失原因。例如 137 帧任务缺少逐帧接触追踪，超过诊断补测的 100 帧上限。 |

一次目标分析最多提交 1 个诊断任务，也可把补测次数设为 0。诊断任务上限为 100 帧和 600 秒。球体与布料支持按物理帧汇总近距离约束列表峰值。最近原生画面会显示实际帧号和偏移，例如目标第 23 帧关联原生第 29 帧并标注 +6。诊断步耗时包含追踪开销，计数的解释范围是场景内的非地面近距离约束。可下载含工具动作、计划和证据引用的目标 JSON。 [三种分支复核](BenchAgent_论文材料/目标驱动案例/三点验收复核.json) · [目标驱动验收报告](BenchAgent_目标驱动验收报告.md)

需要分析材料变化时，在「历史实验分析」页签打开「对照两组真实归档」，选取两个用例和「单项布片材料参数」，点击「检查可比性并计算对照」。系统核对场景、网格、初态、时间步、构建、GPU 和实际材料。密度作为单项变量时，允许对应的初始质量变化。插桩诊断归档会被排除在性能基准对照之外。单次运行的差异用于描述本组条件。 [材料对照与真实归档](material_gpu_evidence/acceptance-374fcca3717f4c2b9d72661bfee704e3/result.json)

## 指标、画面与导出

| 证据 | 查看方式 |
| --- | --- |
| 状态与日志 | 在任务区看已采集帧数、退出结果、stdout／stderr。开启「跟随日志」查看新增输出。 |
| 耗时与迭代 | 物理步耗时按同步物理步计，单位为毫秒。Newton 和逐帧 PCG 累计迭代按归档展示，画面采集耗时单列。 |
| 原生画面 | 在「测试报告 → 概览」展开「原生 OpenGL 画面」。启用采集后，20 帧用例通常保留 0、10、20 帧。 |
| 几何回放 | 已归档状态的固定布料可在任务结果中展开几何回放。可选择归档帧、生成循环播放及下载 GIF。 |
| 报告与证据包 | 在「智能测试 → 结果报告」或「测试报告 → 报告导出」选定当前用例或整个任务集，生成 PDF、Markdown、JSON、CSV 或 ZIP。材料任务的原始 Markdown 和 JSON 可查材料明细，ZIP 保留材料输入与原生生效记录。 |

## 智能工作台 v2 的会话与草稿

「新建对话」开启一份新的任务上下文，已保存的计划、历史任务和实验数据继续保留。快捷建议仅填入输入框，点击「发送并预览」后才进行解析或模型调用。对话和手动修改均通过现有参数校验与计划冻结接口。

生成的计划自动保存到实验记录，「保存草稿」可核对保存状态。材料对照表展示修改前值、计划值、单位与变更状态。执行后可在「结果报告」查看实际生效记录和原始证据。

历史实验分析的诊断预算仍为 0 或 1 次，每次最多 100 帧、600 秒。分析及补测使用已有任务编排接口。原型中的示例数据由真实归档内容替代。
